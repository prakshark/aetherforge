# Aetherforge

Living 3D flood-resilience worlds where AI agents think, argue, build, and self-correct — visibly.

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000 — press **Try demo**, then click the flood zone or Harbor Road to inject a constraint.

## Demo

Use the in-app **How to use** and **90s pitch** buttons for the judging script and WiFi-fallback checklist.
