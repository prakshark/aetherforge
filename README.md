## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000 — press **Try demo**, then click the flood zone or Harbor Road to inject a constraint.

## Demo

Use the in-app **How to use** button for the judging script and WiFi-fallback checklist.
